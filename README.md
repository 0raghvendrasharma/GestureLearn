# Gesture Learn ✋📚

## Description 📝
Gesture Learn is a platform focused on gesture recognition and sign language detection using Streamlit and OpenCV. It offers two main features: Gemini Math Solver and Sign Language Detection.

## Features 🌟
- Gemini Math Solver ➗
- Sign Language Detection 🤟

## Installation 🛠️
To install the required dependencies, run the following commands:

```bash
pip install -r requirements.txt
```

For system packages, run:

```bash
sudo apt-get install $(cat packages.txt)
```

## Usage 🚀
To run the application, use the following command:

```bash
streamlit run mainStream.py
```

## Purpose 🎯
The purpose of this project is to provide a platform for gesture recognition and sign language detection. It aims to help users learn and interact with sign language and solve mathematical problems using gestures.
